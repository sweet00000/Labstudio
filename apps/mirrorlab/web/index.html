MODEL NOTES

What the light is doing.

This bench intersects 3D rays with analytic surfaces and reflects them using d′ = d − 2(d · n)n. Drawing detail does not control optical accuracy.

Mirror geometry

Spherical sag is R − √(R² − r²). A paraboloid has sag r² / (2R), with focal length R / 2. Plane mirrors have no focusing power. Mirror pitch and yaw rotate the actual surface.

Display → eye

Each of nine field points launches its own cone. Rays from one point should leave nearly parallel; different points leave at different angles. Ray colors identify fields, not wavelengths.

Birdbath path

The intended branch is display → splitter reflection → curved mirror reflection → splitter transmission → eye. Splitter thickness and all secondary paths are omitted. The maximum branch fraction is Rₛ × ρₘ × (1 − Rₛ).

Reading the results

Exit RMS measures collimation before pupil clipping. Pupil RMS depends on eye position. Power is normalized to the sampled source cone, not the entire display emission. Sparse pupil hits need finer sampling.

These are idealized design studies. The glasses’ real optical prescription, coating data, emitter distribution, finite pixels, aberration targets, and manufacturing tolerances belong in the next validation stage.
